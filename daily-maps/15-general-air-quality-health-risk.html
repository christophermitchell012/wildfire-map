AirWatch: General Air Quality Health Risk

How to read this map
Hazard / signal: active or recent NWS air-quality, smoke, dust, and ash products.
Exposure: CDC/ATSDR 2022 state population.
Consequence / vulnerability: population-weighted CDC/ATSDR overall SVI.

Official NWS products remain distinct from the MitchellCo derived attention score. This map is not AQI and does not estimate pollutant concentration.
Where are current or very recent air-quality-related NWS products most likely to affect larger, more vulnerable populations?
Active NWS products render first in one request. If none are active, AirWatch automatically shows qualifying products issued in the previous 72 hours as a clearly labeled recency layer instead of leaving an unexplained blank map.

Derived attention score
eventHazard = maximum event weight in state, max 55
active multiplier = 1.00
recent multiplier = max(0.25, 1 − ageHours/96)
hazard = eventHazard × multiplier, max 55
exposure = min(20, 2.7 × log10(statePopulation + 1))
weightedSVI = Σ(countyPopulation × countySVI) / Σ(countyPopulation)
vulnerability = 25 × weightedSVI
attention = hazard + exposure + vulnerability, capped 100
Recent products are context, not active warnings. Dust/smoke products can reflect visibility hazards as well as air-health concerns, so the derived score must not be interpreted as AQI.
Reliability & performance
The active NWS query uses one request with multiple event filters. A 72-hour NWS history request is lazy and runs only when the active result is empty. Polling uses in-memory ETag / If-None-Match when available. CDC uses one grouped statistics request for all states, including a server-side weighted-SVI numerator. Only normalized per-state population is persisted in localStorage for 15 days. NWS zone geometry is cached separately in IndexedDB because zones are relatively static. Cache failures are nonfatal and each source fails independently.
