What this map means

GDELT geolocates places mentioned near breaking-news terms across global news coverage. NewsPulse emphasizes locations where the current mention rate is elevated versus a longer recent baseline. Media volume is attention, not event severity, and automated geocoding can be wrong.

Derived news intensity

Acceleration = current hourly rate / trailing hourly rate
Current rate = current count / selected hours
Trailing rate = max(0.25, (48h count - current count) / (48 - selected hours))
Intensity = min(100, 20×ln(1+current count) + 25×ln(max(1,acceleration)))

Derived/non-official. It measures acceleration and volume only. It does not measure casualties, damage, truth, importance or severity.

Refresh / provenance

GDELT GEO 2.0 updates about every 15 minutes. NewsPulse refreshes every 30 minutes. Requests have a 12-second timeout, are staggered and back off after failures. GEO results include ADM1 and city/landmark locations to reduce the chance that a narrow city-only query returns an empty map.
