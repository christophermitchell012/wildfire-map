What this map means

GDELT geolocates places mentioned near breaking-news topics across global coverage. A keyless GitHub Actions job reads GDELT's raw 15-minute files via lastupdate.txt and writes a same-origin snapshot for this page. Media volume is attention, not event severity, and automated classification/geocoding can still be wrong.

Derived news intensity

Acceleration = current hourly rate / trailing hourly rate
Current rate = current count / selected hours
Trailing rate = max(0.25, (48h count - current count) / (48 - selected hours))
Intensity = min(100, 20×ln(1+current count) + 25×ln(max(1,acceleration)))

Derived/non-official. It measures acceleration and volume only. It does not measure casualties, damage, truth, importance or severity.

Refresh / provenance

GDELT publishes raw update files about every 15 minutes. The repository snapshot job is scheduled at :07 and :37 each hour. This page checks the same-origin snapshot every 5 minutes, so a new GitHub-generated snapshot should appear shortly after the scheduled job finishes.
