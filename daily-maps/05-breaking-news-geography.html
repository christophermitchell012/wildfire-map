What this map means

GDELT geolocates places mentioned near breaking-news terms across global news coverage. When browser access to GDELT GeoJSON works, NewsPulse calculates location acceleration against a 48-hour baseline. If the browser blocks the GeoJSON request, the map automatically switches to GDELT's official embeddable HTML map so current locations still appear.

Derived news intensity

Acceleration = current hourly rate / trailing hourly rate
Current rate = current count / selected hours
Trailing rate = max(0.25, (48h count - current count) / (48 - selected hours))
Intensity = min(100, 20×ln(1+current count) + 25×ln(max(1,acceleration)))

Derived/non-official. These metrics are available only when GeoJSON loads successfully. Media volume is attention, not severity or truth.

Refresh / provenance

GDELT GEO 2.0 updates about every 15 minutes. NewsPulse refreshes every 30 minutes. Direct GeoJSON requests use the documented API. If those requests fail at the browser/network layer, NewsPulse uses GDELT's documented HTTPS iframe-compatible HTML output instead of an unsupported JSONP workaround.
