Derived score
County internal-point screening: SPC category + tornado probability + active warning/watch + population, capped at 100. Missing optional hazard or population inputs are treated as zero rather than blocking the ranking.
Sources & cadence
NOAA/NWS SPC: checked every 15 min.

NWS Alerts API: checked every 2 min.

NWS Local Storm Reports: checked every 30 min.

U.S. Census TIGERweb 2025 generalized counties: static per session.

Esri Living Atlas ACS population/housing county layer: public anonymous service derived from U.S. Census ACS; loaded once per session. Direct Census Data API is not used because it now requires an API key.
