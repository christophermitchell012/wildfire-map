Method

Markers reproduce official USGS Volcano Alert Level and Aviation Color Code categories. Marker size is a MitchellCo display aid only: WARNING=18 px, WATCH=15 px, ADVISORY=12 px, NORMAL=9 px. Size is not a probability, forecast, or official numeric risk score. Only volcanoes shown by USGS with elevated current status in this snapshot are plotted; absence from this layer does not mean a volcano has no long-term hazard.
